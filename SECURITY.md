# Security policy

## Supported versions
The latest release on the default branch.

## Reporting a vulnerability
Please report suspected vulnerabilities in the toolkit itself (for example report injection, unsafe file handling, or any code path that could change a domain) through a private security advisory on this repository. Include the command, PowerShell version and sanitized output. Do not include real directory data.

## Scope notes
The toolkit is a read-only assessment aid for authorized use. It does not exploit vulnerabilities or attack credentials. See [docs/security-and-limitations.md](docs/security-and-limitations.md).
