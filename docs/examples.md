# Examples

All examples run offline against the synthetic sample unless marked **live**. Run them from the repository root after `Import-Module ./src/ADSecurityAudit.psd1 -Force`.

## 1. Audit and export all formats

```powershell
$report = Invoke-ADSecurityAudit -SnapshotPath ./sample-data/contoso-sim.snapshot.json -OutputPath ./output/ex1
$report.OutputFiles
```

## 2. Run only some modules

```powershell
$report = Invoke-ADSecurityAudit -SnapshotPath ./sample-data/contoso-sim.snapshot.json -Module Acl, Delegation
$report.Findings | Where-Object Status -eq 'FAIL' | Format-Table Severity, RuleId, AffectedObject -AutoSize
```

Rules of other modules show in coverage as `NOT_ASSESSED` ("Module was not selected for this run").

## 3. Custom thresholds, an exclusion and a documented exception

`examples/custom-config.json` is a complete, valid example.

```powershell
Test-ADSAConfig -Path ./examples/custom-config.json
$report = Invoke-ADSecurityAudit -SnapshotPath ./sample-data/contoso-sim.snapshot.json -ConfigPath ./examples/custom-config.json -Module PrivilegedAccess
$report.Findings | Where-Object { $_.Excepted } | Format-List RuleId, AffectedObject, Exception
```

Expected: the `ADSA-PRV-004` finding for `svc_backup` is marked excepted by `EXC-001` and is not counted in active findings.

## 4. List rules

```powershell
Get-ADSARuleCatalog -Module Acl | Format-Table Id, Severity, Confidence, Title -AutoSize
Get-ADSARuleCatalog -Id 'ADSA-POL-*' | Select-Object Id, Title
```

## 5. Query a report

```powershell
$report = Invoke-ADSecurityAudit -SnapshotPath ./sample-data/contoso-sim.snapshot.json
# Critical and high active findings
$report.Findings | Where-Object { $_.Status -eq 'FAIL' -and -not $_.Excepted -and $_.Severity -in 'Critical', 'High' } |
    Sort-Object Severity | Format-Table Severity, RuleId, AffectedObject -AutoSize
# Coverage gaps
$report.Coverage.Rules | Where-Object { $_.Status -in 'ERROR', 'NOT_ASSESSED' -or $_.Partial } | Format-Table RuleId, Status, Partial
# Findings per module
$report.Findings | Where-Object Status -eq 'FAIL' | Group-Object Module | Select-Object Name, Count
```

## 6. Compare two runs

```powershell
$before = Get-Content ./examples/sample-reports/sample-report.json -Raw | ConvertFrom-Json
$after = Invoke-ADSecurityAudit -SnapshotPath ./sample-data/contoso-sim.snapshot.json
$key = { "$($_.RuleId)|$($_.AffectedObject)" }
$old = $before.Findings | Where-Object Status -eq 'FAIL' | ForEach-Object $key
$new = $after.Findings | Where-Object Status -eq 'FAIL' | ForEach-Object $key
Compare-Object $old $new
```

No output means identical active findings.

## 7. Share a report with fewer details exposed

```powershell
$report = Invoke-ADSecurityAudit -SnapshotPath ./sample-data/contoso-sim.snapshot.json -Redact -OutputPath ./output/ex7
```

Each run uses a random salt. Pass `-RedactionSalt '<value>'` to get consistent tokens across runs (treat the salt as a secret; with it, names can be confirmed by guessing).

## 8. Validate a report file

```powershell
Test-ADSAReport -Path ./examples/sample-reports/sample-report.json
```

Expected: `IsValid` is `True`.

## 9. Snapshot round trip

```powershell
$snap = Import-ADSASnapshot -Path ./sample-data/contoso-sim.snapshot.json
$file = Export-ADSASnapshot -Snapshot $snap -OutputPath ./output/ex9 -FileName copy.snapshot.json
Invoke-ADSecurityAudit -SnapshotPath $file.FullName -Module Infrastructure | Select-Object -ExpandProperty Summary
```

```powershell
./examples/Invoke-OfflineAudit.ps1
```

## 11. Live, read-only audit of an authorized test domain (**live, optional**)

```powershell
./examples/Invoke-LiveAudit.ps1 -Server dc01.lab.example -SkipDcHostChecks
```

See [walkthrough exercise 3](walkthrough.md#exercise-3-optional-authorized-test-domain) for prerequisites and data handling.

## 12. Collect once, analyse many times (**live, optional**)

```powershell
$cred = Get-Credential
$report = Invoke-ADSecurityAudit -AuthorizedAssessment -Server dc01.lab.example -Credential $cred -SaveSnapshotPath ./output/snapshots
```

The snapshot file in `output/snapshots` contains raw directory data; delete it after use.

## Committed sample reports

`examples/sample-reports/` holds reports generated by `./scripts/Invoke-Demo.ps1 -UpdateSampleReports` from the synthetic snapshot: `sample-report.json|csv|html` and a redacted pair. They are labelled **Simulated** and do not describe any real environment.
